## 💭 Reflection

Working on the `event_manager` project gave me hands-on experience as a QA Analyst/Developer in a collaborative, real-world-like environment. One of the key lessons I learned was how to identify and resolve edge-case validation issues in user authentication systems. By refining username validation to disallow special characters, I enhanced the system’s robustness and user experience. I also deepened my understanding of regex and how FastAPI handles Pydantic-based validations.

From a collaborative standpoint, I gained valuable experience using GitHub best practices such as working on feature branches, creating clear pull requests, and contributing to an upstream repository via forks. It was especially challenging to troubleshoot Docker Compose service issues and manage multi-container setup, but I’m now more comfortable with debugging containerized environments.

Overall, this assignment helped me strengthen both my Python testing skills and my ability to contribute meaningfully in team-based software development projects. It has also shown me how small QA improvements—like input validation—can significantly improve product quality.
